# ORION Community Portal

A responsive membership portal for an engineering community focused on real projects, industry exposure, startups, and peer learning.

[View the live site](https://orion-crew-gecw.vercel.app)

## Highlights

- Clear community benefits and joining process
- Responsive glassmorphism interface
- Scroll animations, preloader, and interactive navigation
- Membership application form
- Google Forms integration with success feedback
- Direct community and professional links

## Stack

`HTML` · `Tailwind CSS` · `JavaScript` · `Lucide Icons` · `Google Forms`

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
